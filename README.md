# Memory - Найди пару

Классическая игра на память, где нужно находить пары одинаковых карточек, переворачивая их по очереди.

## 🎮 Как играть

1. Кликните на карточку - она перевернётся
2. Кликните на вторую карточку — если символы совпали, пара останется открытой
3. Если не совпали - карточки перевернутся обратно
4. Цель — найти все пары за минимальное время и количество ходов

## 🚀 Запуск

Откройте файл `index.html` в любом современном браузере.

## 🎯 Особенности

- 3 уровня сложности: 4×4, 6×4, 6×6
- 3D-анимация переворота карточек
- Подсчёт времени и количества ходов
- Система подсказок
- Анимации появления и совпадения
- Адаптивный дизайн для мобильных устройств

## ⚙️ Управление

| Кнопка | Описание |
|--------|----------|
| 4×4, 6×4, 6×6 | Выбор сложности |
| 💡 Подсказка | Показать пару карточек |
| 🔄 Новая игра | Начать заново |

## 🛠️ Технологии

- HTML5

- ✅ Найденные пары
